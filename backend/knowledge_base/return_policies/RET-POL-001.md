# Standard Returns Policy
Document ID: RET-POL-001 | Version: 3.2 | Effective date: 2025-01-01

## Section 3.1: Standard return window
Eligible unused products may be returned within 30 calendar days after confirmed delivery. The delivery event in the shipment record is the authoritative start date. Items must include the original accessories and be in resalable condition.

## Section 3.2: Late return review
Requests after 30 days are not automatically eligible. Operations may review documented delivery damage, carrier delay, accessibility needs, or a previously opened support case. Do not promise a refund before an authorized reviewer approves an exception.

## Section 3.3: Wrong or missing item
When the order contents differ from the received contents, open an investigation case. Request packaging or product evidence only when practical. A replacement or refund requires verification and the applicable approval.

## Section 3.4: Duplicate requests
Check for an existing return for the same order and item before creating another case. Update the existing case instead of creating a duplicate.
