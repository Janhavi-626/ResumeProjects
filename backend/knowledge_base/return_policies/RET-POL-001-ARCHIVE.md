# Archived Returns Policy
Document ID: RET-POL-001 | Version: 2.0 | Effective date: 2023-01-01

## Section 3.1: Historical return window
ARCHIVED AND SUPERSEDED: a historical draft described a 45-day return window. Do not apply this retired rule. The current RET-POL-001 version 3.2 sets the standard window to 30 days.
